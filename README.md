# My First Webpage

## Project Overview

This project is my first personal webpage created for the Web Technologies 1 course at Astana IT University.

The main purpose of this project is to practice the basic concepts of HTML and CSS.

HTML was used to create the structure and content of the webpage, while CSS was used to change the appearance of the webpage.

The website contains information about me, my hobbies, favorite websites, an image, a weekly class schedule, and a simple contact form.

---
